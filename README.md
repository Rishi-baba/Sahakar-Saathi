# Sahakar-Saathi

> **A Voice-First, Offline-Capable AI Assistant for Cooperative Members and Farmers**  
> *Developed for Smart India Hackathon 2025 • Team Diamonds*

---

## 🌟 Overview

**Sahakar Saathi** bridges the digital divide for India's 63,000+ Primary Agricultural Credit Societies (PACS) and millions of rural farmers. It provides:

- 🎙️ **Voice-First AI** in local languages (मराठी, हिन्दी, English, తెలుగు, বাংলা) powered by Indic voice models (AI4Bharat & Bhashini).
- 🛡️ **Zero-Hallucination Grounded Answers** citing official gazettes, PMFBY Guidelines, MSCS Act 2023, and Model By-laws.
- 📶 **Offline-Edge Resilience** deployable on village PACS kiosks with cached SQLite/ONNX local retrieval.
- ⚖️ **3-Tier Statutory Grievance Redressal** with automated escalation: `PACS Secretary → Assistant Registrar → Ombudsman`.
- 🌾 **4-Step Scheme Eligibility Engine** with instant pre-application at PACS desks.
- 🖨️ **Rural PACS Kiosk Terminal Mode** with tactile buttons and thermal print receipt preview.

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/Rishi-baba/Sahakar-Saathi.git

# Navigate to project directory
cd Sahakar-Saathi

# Install dependencies
npm install

# Run locally
npm run dev

# Build for production
npm run build
```
